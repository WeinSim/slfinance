Usage:
    slfinance [<command>] [<options>]

Commands:
    list                    Prints an overview of the current tracker.

Options:
    --help, -h              Prints this help message and exists.

    --version, -v           Prints version and copyright information and exists.

    --file, -f <file>       Opens the specified file. If this option is not specified, the
                            file stored in ~/.slfinance/settings.json is loaded.

    --show-categories, -c   Shows each category in a separate column.
