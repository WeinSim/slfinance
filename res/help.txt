Usage:
    slfinance [<command>] [<options>]

Commands:
    list                    Prints an overview of the current tracker.

    convert <input-file> <output-file>
                            Converts a TSV file into the standard SLF json format.

    add <list> <category> <amount>
                            Adds an entry to <list>, which can be either 't' or 'total' to
                            add to the list of total money, 'i' or 'income' to add an
                            income or 'e' or 'expenses' to add an expense.
                            If <category> doesn't exist, a new category will be created.
                            The entry will be inserted into the current month / year.
                            <amount> should be an integer, which is interpreted as euros.

Options:
    -h, --help              Prints this help message and exists.

    -v, --version           Prints version and copyright information and exists.

    -f, --file <file>       Opens the specified file. If this option is not specified, the
                            file stored in ~/.slfinance/settings.json is loaded.
                            Accepted by 'list' and 'add'.

    -c, --show-categories   Shows each category in a separate column.
                            Accepted by 'add'.

    -d, --description <description>
                            Adds a description when adding an entry.
                            Accepted by 'add'.

    -D, --date <date>       Specifies a date when adding an entry. The date must be in the
                            format "yyyy-mm-dd". By default, the current date will be
                            used. Use '--date ""' to insert an entry without a date.
                            Accepted by 'add'.

    -m --month <month>      Specifies a month when adding an entry. This argument cannot
                            be used in combinatino with --date. <month> can be either a
                            number from 1 to 12 or the start of a month, e.g. 'jan' or
                            'January'. The match is case-insensitive.
