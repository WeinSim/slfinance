Usage:
    slfinance [<command>] [<options>]

Commands:
    list                    Prints an overview of the current tracker.
                            With the --month or --year flags given, prints individual
                            entries of only the given month.

    convert <input-file> <output-file>
                            Converts a TSV file into the standard SLF json format.

    add <category> <amount>
                            Adds an entry to the specified list (see --total, --incomes
                            and --expenses). If <category> doesn't exist, a new category
                            will be created. If no date or month / year is specified, the
                            entry will be inserted into the current month / year. <amount>
                            can be literal (with '.' as the decimal point) or a formula
                            consisting of literals , addition, subtraction, right
                            multiplication and division by integers as well as
                            parentheses.

Options:
    -h, --help              Prints this help message and exists.

    -v, --version           Prints version and copyright information and exists.

    -f, --file <file>       Opens the specified file. If this option is not specified, the
                            file stored in ~/.slfinance/settings.json is loaded.
                            Accepted by 'list' and 'add'.

    -c, --show-categories   Shows each category in a separate column.
                            Accepted by 'list'.

    -t, --total             Adds to the / shows the 'total' list.
                            Accepted by 'list' and 'add'.

    -i, --incomes           Adds to the / shows the 'incomes' list.
                            Accepted by 'list' and 'add'.

    -i, --expenses          Adds to the / shows the 'expenses' list.
                            Accepted by 'list' and 'add'.

    -d, --description <description>
                            Adds a description when adding an entry.
                            Accepted by 'add'.

    -D, --date <date>       Specifies a date when adding an entry. <date> must be in the
                            format "yyyy-mm-dd". Without this option, the current date
                            will be used. Use --date "" to insert an entry without a
                            date. The date must be between Jan 1, 262145 BCE and Dec 31,
                            262143 CE, inclusive.
                            Accepted by 'add'.

    -m, --month <month>     Specifies a month when adding an entry. This argument cannot
                            be used in combination with --date. <month> can be either a
                            number from 1 to 12 or the start of a month name, e.g. 'jan'
                            or 'January'. The match is case-insensitive. The given month
                            will be combined with the current year.
                            Accepted by 'list' and 'add'.

    -y, --year <year>       Specifies a year when adding an entry. This argument cannot be
                            used in combination with --date. <year> can be any integer
                            between -2147483648 and +2147483647 inclusive. Inputs between
                            0 and 99 inclusive will be adjusted to the current / last
                            century (i.e. --year 26 will be interpreted as 2026). To avoid
                            this conversion, prefix the year with a zero: --year 026. The
                            given year will be combined with the current month.
                            Accepted by 'list' and 'add'.

    -my, --month-year <month> <year>
                            Combination of --month and --year.
                            Accepted by 'list' and 'add'.
